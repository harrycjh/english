# VocaRabbit 统计页设计

日期：2026-05-08

## 1. 设计目标

统计页不是给孩子看的炫技图表页，而是给家长做判断的仪表盘。

这页要快速回答 4 个问题：

1. 今天学完了吗。
2. 最近有没有坚持在学。
3. 现在最薄弱的是哪些词、哪些主题。
4. 接下来几天复习会不会堆积。

设计原则：

- 先做能驱动决策的统计，不做信息噪声很大的图。
- 先匹配当前已有数据模型，不空想不存在的数据。
- 所有统计模块都应该能导向下一步动作，而不是只展示数字。

## 2. 页面定位

统计页属于四个主页面之一，对应底部导航中的“统计”。

它和复习页、选词页的关系如下：

- 复习页回答“今天学什么”。
- 选词页回答“学哪些词”。
- 统计页回答“学得怎么样”和“接下来会不会堆积”。

因此统计页不是独立系统，而是复习页和选词页的反馈层。

## 3. MVP 能力边界

### 3.1 现有模型能支撑的统计

根据当前 [vocab_rabbit/src/models/daily-task.ts](vocab_rabbit/src/models/daily-task.ts)、[vocab_rabbit/src/models/learning-record.ts](vocab_rabbit/src/models/learning-record.ts) 和 [vocab_rabbit/src/models/word.ts](vocab_rabbit/src/models/word.ts)，MVP 可靠能做：

- 今日完成率
- 最近完成热力图
- 连续学习天数
- 已掌握 / 学习中 / 未学分层
- 高频错误词
- 按主题错误热点
- 未来 3 天 / 7 天复习压力

### 3.2 当前模型暂时做不准的统计

当前还没有“每次答题事件日志”，所以以下统计先不进入 MVP：

- 按题型正确率趋势
- 某天具体错了哪些词几次
- 单词在不同日期的错误轨迹
- 更细的遗忘曲线拟合

如果后续要做这些，需要新增答题事件日志模型，而不是硬凑。

## 4. 页面结构

推荐布局：iPad 横屏三段式仪表盘。

```text
┌──────────────────────────────────────────────────────────────┐
│ 统计页标题   时间范围切换   今日完成率   连续天数   未来3天压力 │
├──────────────────────────────────────────────────────────────┤
│ 概览卡1   概览卡2   概览卡3   概览卡4   概览卡5   概览卡6      │
├──────────────────────────────┬───────────────────────────────┤
│ 左侧：热力图 + 完成趋势        │ 右侧：掌握结构 + 压力预测     │
├──────────────────────────────┼───────────────────────────────┤
│ 左下：高频错误词              │ 右下：错误主题 + 行动建议      │
└──────────────────────────────┴───────────────────────────────┘
```

页面节奏：

- 第一屏先给“总览结论”。
- 第二屏展示“结构”。
- 第三屏展示“问题点”和“建议动作”。

## 5. 模块清单

### 5.1 顶部概览条

目标：在 3 秒内让家长知道当前状态。

建议放 6 张概览卡：

1. 今日完成率
2. 连续学习天数
3. 已掌握词数
4. 学习中词数
5. 最近 7 天平均正确率
6. 未来 3 天预计复习量

交互：

- 点击“今日完成率”滚动到最近任务明细。
- 点击“已掌握词数”高亮掌握结构模块。
- 点击“未来 3 天预计复习量”高亮压力预测模块。

### 5.2 学习活动模块

目标：回答“最近有没有持续学习”。

包含两部分：

- 14 天热力图
- 7/14/30 天完成趋势图

热力图表达维度：

- 是否完成当日任务
- 完成题量强弱

趋势图表达维度：

- 每天完成题数
- 每天正确率

MVP 推荐先做柱状趋势，不一定先上折线图。

### 5.3 掌握结构模块

目标：回答“学到哪一层了”。

建议分 5 桶：

1. 未学：没有 LearningRecord 的词
2. 刚开始：masteryLevel 0-1
3. 学习中：masteryLevel 2-3
4. 已掌握：masteryLevel 4-5
5. 很稳：masteryLevel 6

另外保留“已暂停”作为附加状态，但它需要后续设置页和选词页联动后再完整上线。

展示方式：

- 环形分布图或横向堆叠条
- 每一层显示词数和占比

交互：

- 点击某一层，跳去筛出该层级的词列表。
- 点词数文本时，打开单词详情抽屉或跳到选词页过滤结果。

### 5.4 高频错误词模块

目标：回答“最近最该优先补哪几个词”。

列表字段建议：

- 英文
- 中文
- 分类
- 错误次数
- 当前掌握等级
- 下次复习时间

排序建议：

1. wrongCount 降序
2. masteryLevel 升序
3. nextDueAt 近的优先

MVP 先展示前 10 个词足够。

交互：

- 点某个词：打开单词详情抽屉。
- 点“去复习”：跳回复习页并把该词加入优先复习队列。

### 5.5 错误主题模块

目标：回答“不是某个词难，而是哪一类词整体难”。

做法：把 WordRecord.category 和 LearningRecord.wrongCount 聚合。

展示字段：

- 分类名
- 分类下已学词数
- 总错误次数
- 平均错误密度

展示形式：

- 排名前 5 的主题条形图
- 每个主题配一个“去选词页查看”入口

### 5.6 未来复习压力模块

目标：回答“接下来几天会不会爆量”。

根据 nextDueAt 做日期分桶：

- 明天到期数
- 未来 3 天到期总数
- 未来 7 天到期总数
- 峰值日是哪一天

可视化：

- 小型柱状图
- 风险标签：正常 / 偏高 / 过高

建议规则：

- 正常：未来 3 天平均复习量 <= dailyReviewLimit
- 偏高：未来 3 天平均复习量在上限的 1.0 到 1.5 倍
- 过高：未来 3 天平均复习量 > 上限的 1.5 倍

### 5.7 行动建议模块

目标：统计页不能只看数据，还要给家长下一步操作。

建议动作只做 3 类：

1. 降低明日新词数
2. 只复习不加新词
3. 去选词页收缩某个主题

显示逻辑：

- 如果未来压力偏高，优先显示“降低明日新词数”。
- 如果某主题错误明显高，显示“去调整该主题启用词”。
- 如果连续 3 天没完成，显示“切回低难度 / 降低任务量”。

## 7. 数据计算口径

### 7.1 今日完成率

来源：DailyTaskSummary

公式：

- 如果 totalAnswered = 0，则显示 0%
- 否则显示 correctCount / totalAnswered 作为正确率
- 今日任务是否完成则看 completedAt 是否存在

注意：

- 正确率和完成率是两个概念，页面文案要分开。
- “今日完成率”更适合作为任务完成状态。
- “今日正确率”更适合作为表现指标。

### 7.2 连续学习天数

来源：DailyTaskSummary 列表

规则：

- 从今天往前数，completedAt 非空且日期连续则累计。
- 碰到第一天空缺则停止。

### 7.3 已掌握词数

来源：LearningRecord

规则：

- 与当前代码一致，masteryLevel >= 4 视为已掌握。

### 7.4 高频错误词

来源：LearningRecord + WordRecord

规则：

- wrongCount > 0 的词进入候选集。
- 用 wrongCount、masteryLevel、nextDueAt 排序。

### 7.5 错误主题

来源：LearningRecord + WordRecord.category

规则：

- 将所有已学词按 category 聚合。
- 主题错误度 = 该主题所有词 wrongCount 总和 / 已学词数。

### 7.6 未来压力

来源：LearningRecord.nextDueAt + ParentSetting.dailyReviewLimit

规则：

- 把 nextDueAt 落入未来 1、3、7 天窗口的词数统计出来。
- 如果没有设置 dailyReviewLimit，则使用默认值。

## 8. 页面状态

### 8.1 首次使用

当还没有任何 DailyTaskSummary 或 LearningRecord 时：

- 不展示空白图表。
- 显示引导卡：先开始第一次学习。
- 提供“去复习页”按钮。

### 8.2 有学习记录但很少

当学习天数少于 3 天时：

- 热力图仍可显示。
- 趋势图显示最近可用数据。
- 高级趋势文案用“数据积累中”。

### 8.3 数据异常

如果 DailyTaskSummary 存在但 WordRecord 映射缺失：

- 保留统计页可用部分。
- 在局部模块中显示“部分词数据缺失”。

## 9. 与其他页面的联动

### 9.1 跳去选词页

从统计页跳去选词页的典型入口：

- 点击高错误主题
- 点击已掌握分层中的某一桶
- 点击未来压力建议中的“收缩词量”

### 9.2 跳去复习页

从统计页跳去复习页的典型入口：

- 点击“去复习薄弱词”
- 点击“继续今日任务”

### 9.3 打开详情抽屉

从统计页打开详情抽屉的典型入口：

- 高频错误词
- 最近学习过的代表词

## 10. 建议新增的数据模型

如果进入第二阶段，建议新增：

```ts
interface AnswerEvent {
  id: string;
  wordId: string;
  questionKind: 'image-choice' | 'text-choice' | 'fill-blank';
  isCorrect: boolean;
  answeredAt: string;
}
```

有了这个模型之后，统计页可以进一步支持：

- 按题型正确率趋势
- 按日期的错误轨迹
- 更精细的薄弱点分析

## 11. 推荐实现顺序

### Phase 1

- StatisticsPage 页面框架
- 顶部概览卡
- 热力图
- 掌握结构
- 高频错误词
- 未来压力预测

### Phase 2

- 趋势图
- 错误主题模块
- 行动建议模块
- 和选词页、复习页的跳转联动

### Phase 3

- AnswerEvent 模型
- 按题型趋势
- 更细的周报和导出能力

## 12. 结论

统计页的价值不在于“图多”，而在于把家长真正需要的判断压缩成几块：

- 今天完成了没有
- 最近坚持得怎么样
- 哪些词和主题最弱
- 接下来几天会不会堆积

只要围绕这 4 个问题设计，统计页就会成为 VocaRabbit 的决策面板，而不是一个看起来很忙但实际上没法指导下一步操作的页面。
