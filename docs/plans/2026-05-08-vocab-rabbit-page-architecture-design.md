# VocaRabbit 页面架构设计

日期：2026-05-08

## 1. 目标

这份设计用于把 VocaRabbit 的网页端结构从“已有原型页面”推进到“可持续扩展的页面体系”。

设计基线：

- 目标设备是 iPad，横屏优先。
- v1 重点是儿童学习端和家长轻管理，不做复杂社交或云同步。
- 页面设计借鉴墨墨背单词的三类核心能力：抗遗忘调度、词库管理、统计反馈；但不照搬成人备考流程。

本设计把产品收敛为 4 个主页面、2 个流程页面、1 个通用详情抽屉。

## 2. 页面总览

### 2.1 四个主页面

1. 复习页
2. 选词页
3. 统计页
4. 设置页

### 2.2 两个流程页面

1. 学习页
2. 完成页

### 2.3 一个通用覆盖层

1. 单词详情抽屉

## 3. 导航结构

底部固定四按钮导航保持全局一致：

- 复习
- 选词
- 统计
- 设置

导航规则：

- 复习：进入默认首页，展示今日学习任务和开始学习入口。
- 选词：进入词库配置页，筛选、查看和启用词。
- 统计：进入家长视角仪表盘，查看完成度、错误热点和未来压力。
- 设置：进入学习参数与本地数据设置页。

流程页面不出现在底部导航中：

- 点击“开始学习”进入学习页。
- 学习完成后进入完成页。
- 完成页点击“返回首页”回到复习页。

通用详情抽屉可从复习页、选词页、统计页中的任意单词入口打开。

## 4. 页面职责

### 4.1 复习页

这是默认首页，也是打开应用后最先进入的页面。

核心职责：

- 告诉用户今天该做什么。
- 让用户尽量用最少点击开始学习。
- 提供家长快速判断当日压力的入口。

MVP 模块：

- 今日任务总览：新词数、复习数、预计时长。
- 继续学习按钮：直接进入学习流程。
- 四词预览：用一排四卡展示今日代表性单词。
- 14 天热力图缩略版。
- 今日任务摘要卡：今日任务、分类数量、最近学习痕迹。
- 底部四按钮导航。

增强模块：

- 今日建议：今天适合做多少新词。
- 最近完成趋势。
- 未完成任务提醒。

### 4.2 选词页

这是家长配置学习范围的主页面。

核心职责：

- 从全部词库中筛选出当前孩子该学的词。
- 显示启用范围对未来学习压力的影响。
- 支持快速批量操作，而不是逐词点选。

MVP 模块：

- 顶部总览条：启用词数、已掌握词数、未来 3 天复习压力。
- 左侧筛选栏：分类、Level、难度、词性、状态、是否有图片。
- 中间单词区：默认一行四卡，也支持列表视图。
- 右侧已选词篮：显示当前启用词和压力预估。
- 批量操作：加入当前筛选结果、移除当前筛选结果。
- 搜索：按英文或中文搜索。
- 单词详情抽屉入口。

增强模块：

- 词量测试后推荐词范围。
- 自定义词单保存。
- 只启用有图片/有例句的词。

### 4.3 统计页

这是家长看学习结果和未来复习压力的仪表盘。

核心职责：

- 判断今天学得怎么样。
- 找出最薄弱的词和主题。
- 预警未来 3 到 7 天的复习堆积风险。

MVP 模块：

- 顶部概览卡：今日完成率、连续学习天数、已掌握词数、未来 3 天压力。
- 14 天热力图。
- 学习趋势图：7/14 天完成情况。
- 掌握结构：未学、学习中、已掌握、已暂停。
- 高频错误词列表。
- 按主题错误率。
- 未来复习压力预测。

增强模块：

- 题型正确率趋势。
- 每周自动报告。
- CSV 导出。

### 4.4 设置页

这是家长管理学习策略和本地数据的页面。

核心职责：

- 调整每天学习量。
- 控制发音、图片、例句等体验开关。
- 管理本地学习数据和安装提示。

MVP 模块：

- 每日新词数量。
- 每日复习上限。
- 发音开关。
- 图片显示开关。
- 例句显示开关。
- 本地数据重置。
- 数据导出/导入。
- PWA 安装提示。

增强模块：

- 多套学习方案切换。
- 家长锁。
- 主题皮肤选择。

## 5. 流程页面

### 5.1 学习页

学习页是主流程，不属于信息架构中的驻留页面。

职责：

- 承载今天被分配到的学习队列。
- 根据 masteryLevel 自动切换题型。
- 在答错时把词回流到队尾。
- 在正确后给出简短正反馈并自动推进。

必备模块：

- 当前题目区。
- 发音按钮。
- 进度环。
- 实时反馈条。
- 返回首页入口。

### 5.2 完成页

职责：

- 结束今日任务。
- 给予儿童友好的成就反馈。
- 提供回到首页或查看薄弱词的入口。

必备模块：

- 今日完成摘要。
- 正确率。
- 错词数量。
- 返回首页按钮。

## 6. 通用详情抽屉

单词详情抽屉是整个系统中最重要的通用覆盖层之一。

任何页面中只要出现单词卡，都应该能打开它。

MVP 内容：

- 英文。
- 中文。
- 词性。
- 发音。
- 图片。
- 牛津树定位。
- 当前学习状态。
- 最近答题记录。

增强内容：

- 例句。
- 助记。
- 错误题型分析。
- 暂停此词 / 重置进度。

## 7. 关键跳转关系

### 7.1 主跳转

- 复习页 -> 学习页：点击开始学习。
- 学习页 -> 完成页：当日任务完成。
- 完成页 -> 复习页：点击返回首页。

### 7.2 次跳转

- 统计页 -> 选词页：点击某个薄弱主题或高错误词范围。
- 选词页 -> 复习页：应用当前选词方案后返回今日任务。
- 任意单词卡 -> 单词详情抽屉。

### 7.3 全局导航

- 四按钮底部导航只在四个主页面出现。
- 学习页和完成页不显示全局导航，避免孩子误触脱离流程。

## 8. 数据依赖

### 8.1 复习页依赖

- DailyTaskSummary
- LearningRecord 聚合结果
- 最近任务历史
- 预览词列表

### 8.2 选词页依赖

- WordPayload 全量词库
- 启用/停用状态
- LearningRecord
- 未来复习压力估算服务

### 8.3 统计页依赖

- DailyTask 历史
- LearningRecord 全量
- 错误日志或答题聚合数据

### 8.4 设置页依赖

- ParentSetting
- 本地存储导入导出接口

## 9. MVP 范围边界

v1 不做：

- 云同步
- 多设备实时共享
- 社区助记
- 复杂成人词书商城
- 排行榜或社交功能

v1 必须完成：

- 四个主页面基础结构
- 学习流程闭环
- 单词详情抽屉
- 词库筛选与启用
- 统计页核心指标
- 设置页基础参数

## 10. 推荐实现顺序

1. 复习页：保证首页和底部导航稳定。
2. 选词页：建立词库筛选与启用逻辑。
3. 设置页：把学习参数外置。
4. 统计页：在数据模型稳定后补仪表盘。
5. 单词详情抽屉：横向接入复习页、选词页、统计页。

## 11. 结论

这套页面架构的核心原则是：

- 孩子只需要看到“今天怎么学”。
- 家长需要看到“学什么、学得怎样、接下来会不会堆积”。
- 页面数量保持克制，但每一页都承担明确职责。

如果后续按这个结构实施，VocaRabbit 就会形成一套清晰的网页产品骨架，而不是持续在首页上堆功能。
