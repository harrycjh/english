# VocaRabbit 复习页设计

日期：2026-05-08

## 1. 设计目标

复习页是 VocaRabbit 的默认首页，也是孩子最常进入的页面。

这页要解决的不是“展示很多信息”，而是让孩子和家长在最短时间内知道三件事：

1. 今天要学多少。
2. 现在是不是可以直接开始。
3. 如果不开始，今天最值得先看的词是什么。

因此复习页的核心原则是：

- 入口极短，尽量一键开始。
- 反馈清晰，家长一眼能判断今天是否轻松或偏重。
- 儿童友好，不在首页堆过多管理能力。

## 2. 页面定位

复习页对应底部导航中的“复习”，也是应用冷启动后的默认页。

它与其他页面的关系：

- 点击开始学习，进入学习页。
- 点击某个预览词，可打开单词详情抽屉。
- 点击底部导航，进入选词页、统计页、设置页。
- 学习完成后，从完成页返回这里。

可以把它理解成“今日任务控制台”，不是完整仪表盘，也不是词库配置页。

## 3. 页面结构

推荐采用上下两段式布局，配合底部四按钮导航。

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部英雄区：今天学什么 + 开始学习                            │
├──────────────────────────────────────────────────────────────┤
│ 中部任务概览：今日任务 / 分类数量 / 最近学习痕迹              │
├──────────────────────────────────────────────────────────────┤
│ 今日预览：一排四个代表词                                     │
├──────────────────────────────────────────────────────────────┤
│ 缩略热力图 / 轻量建议卡                                      │
├──────────────────────────────────────────────────────────────┤
│ 底部四按钮导航：复习 / 选词 / 统计 / 设置                    │
└──────────────────────────────────────────────────────────────┘
```

## 4. 模块清单

### 4.1 顶部英雄区

目标：一眼看到今天任务，并且一键开始。

MVP 内容：

- 今日新词数量
- 今日复习数量
- 词库总数
- 已掌握词数
- 主按钮：开始今日学习 / 继续今日学习

辅助文案建议：

- 任务较轻时：今天安排比较轻松
- 任务偏重时：今天复习稍多，建议先完成复习

### 4.2 任务概览卡

目标：让家长快速判断今天任务强度。

MVP 卡片：

1. 今日任务总数
2. 分类数量
3. 最近 14 天热力图缩略版

增强卡片：

- 预计时长
- 今日正确率预估占位

### 4.3 今日预览区

目标：在开始前先看一眼今天有代表性的词。

MVP 规则：

- 默认展示 4 个词
- 词来自今日任务队列中的代表词
- 一行四卡，iPad 横屏优先

卡片内容：

- 英文
- 中文
- 分类
- 难度
- 牛津树定位

交互：

- 点击卡片，打开单词详情抽屉
- 不在首页直接做启用/暂停操作，避免和选词页职责冲突

### 4.4 学习建议区

目标：给家长一个很轻的判断，不需要复杂统计。

MVP 内容：

- 今天建议先做复习还是先做新词
- 如果未来 3 天压力偏高，给出一句短提示

例如：

- 今天复习较少，可以正常加入新词
- 未来 3 天压力偏高，今天建议先完成复习

### 4.5 底部导航

复习页是四按钮导航的默认激活态。

按钮：

- 复习
- 选词
- 统计
- 设置

行为：

- 点击复习：停留当前页
- 点击其他按钮：进入对应主页面

## 5. 数据依赖

复习页依赖的数据非常明确：

### 5.1 DailyTaskSummary

用于：

- 今日新词数
- 今日复习数
- 是否已完成

### 5.2 LearningRecord

用于：

- 已掌握词数
- 生成预览词时判断代表性

### 5.3 WordPayload

用于：

- 总词数
- 预览词卡内容

### 5.4 ParentSetting

用于：

- 每日新词数
- 每日复习上限
- 是否开启发音

## 6. 页面状态

### 6.1 首次进入

如果没有任何学习记录：

- 顶部显示“今天开始第一组单词”
- 今日预览仍展示默认 4 词
- 热力图为空，但不显示错误状态

### 6.2 当日任务未开始

- 主按钮显示“开始今日学习”
- 任务卡显示建议一次完成

### 6.3 当日任务进行中

- 主按钮显示“继续今日学习”
- 可加一行进度提示，例如“今天已经完成一部分”

### 6.4 当日任务已完成

- 主按钮显示“重新打开今日任务”或“再复习一轮”
- 首页文案改成鼓励语气

### 6.5 数据为空或异常

- 如果词库 JSON 加载失败：显示错误卡
- 如果任务不存在：尝试自动重新生成当日任务

## 7. 关键交互

### 7.1 开始学习

- 点击主按钮进入学习页
- 学习队列来源于当天任务

### 7.2 预览词点击

- 打开单词详情抽屉
- 不跳转新页面

### 7.3 从完成页返回

- 回到复习页
- 英雄区显示“今日完成”状态

### 7.4 压力提示联动

- 如果未来压力偏高，可在首页直接给出“去选词页调整”入口

## 8. 组件建议

- ReviewPage
- ReviewHero
- ReviewTaskSummaryCards
- ReviewPreviewWords
- ReviewSuggestionCard
- ReviewHeatmapPreview

## 9. 与其他页面的联动

### 9.1 与学习页联动

- 复习页发起学习主流程
- 学习页完成后返回复习页

### 9.2 与选词页联动

- 当前启用词范围变化后，复习页要重新刷新代表词和任务强度

### 9.3 与统计页联动

- 首页只显示缩略版趋势，不重复完整统计页职责

## 10. 推荐实现顺序

1. 复用现有 HomePage 骨架作为 ReviewPage
2. 固定顶部英雄区和任务概览结构
3. 接入预览词和热力图缩略版
4. 接入压力提示和详情抽屉入口

## 11. 结论

复习页不应该越来越像“控制后台”，而应该始终保持一键开始学习的节奏感。

它的价值在于：

- 对孩子足够简单
- 对家长足够清楚
- 对整个学习流程足够稳定
