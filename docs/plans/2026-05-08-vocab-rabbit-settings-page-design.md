# VocaRabbit 设置页设计

日期：2026-05-08

## 1. 设计目标

设置页负责家长对学习策略和本地数据的管理。

这页不应该变成“高级系统设置大全”，而应该只保留真正影响日常学习效果的配置项。

它需要解决的核心问题：

1. 每天学多少。
2. 学习时显示哪些辅助内容。
3. 本地数据怎么备份、恢复、重置。

## 2. 页面定位

设置页对应底部导航中的“设置”。

它与其他页面的关系：

- 调整每日新词数和复习上限后，影响复习页和选词页的压力预估。
- 调整发音、图片、例句等开关后，影响学习页和详情抽屉的显示。
- 数据重置后，影响全部页面。

## 3. 当前模型与建议扩展

当前 [vocab_rabbit/src/models/parent-setting.ts](vocab_rabbit/src/models/parent-setting.ts) 只有：

- enableAudio
- dailyNewWordCount
- dailyReviewLimit

要支持设置页 MVP，建议扩成：

```ts
interface ParentSetting {
  enableAudio: boolean;
  dailyNewWordCount: number;
  dailyReviewLimit: number;
  showImages: boolean;
  showExamples: boolean;
  showHints: boolean;
  preferLandscape: boolean;
}
```

说明：

- showImages 决定学习页是否展示图片题资源
- showExamples 决定详情抽屉和学习页是否显示例句
- showHints 决定拼写题是否显示额外提示
- preferLandscape 用于 iPad 端体验提示，不一定直接改变逻辑

## 4. 页面结构

建议采用分组卡片结构，而不是长表单。

```text
┌──────────────────────────────────────────────────────────────┐
│ 设置页标题                                                  │
├──────────────────────────────────────────────────────────────┤
│ 学习量设置卡：每日新词 / 每日复习上限                        │
├──────────────────────────────────────────────────────────────┤
│ 学习体验设置卡：发音 / 图片 / 例句 / 提示                    │
├──────────────────────────────────────────────────────────────┤
│ 设备与安装卡：PWA 安装提示 / 横屏提示                        │
├──────────────────────────────────────────────────────────────┤
│ 数据管理卡：导出 / 导入 / 重置                               │
├──────────────────────────────────────────────────────────────┤
│ 底部四按钮导航                                               │
└──────────────────────────────────────────────────────────────┘
```

## 5. 模块清单

### 5.1 学习量设置卡

目标：控制任务规模。

MVP 内容：

- 每日新词数：建议范围 3-20
- 每日复习上限：建议范围 5-50

交互：

- 用步进器或滑杆，而不是自由输入
- 修改后立即保存到本地
- 页面给出简单反馈，例如“未来压力将同步调整”

### 5.2 学习体验设置卡

目标：控制孩子学习时看到什么。

MVP 开关：

- 发音开关
- 图片显示开关
- 例句显示开关
- 提示显示开关

说明：

- 有些词可能没有图片或例句，关闭开关只是控制界面展示，不改变底层数据。

### 5.3 设备与安装卡

目标：减少 iPad 使用中的环境问题。

MVP 内容：

- 当前是否建议加入主屏
- PWA 安装说明
- 横屏优先提示

增强内容：

- 检测当前是否为 Safari
- 检测是否已以 PWA 形式运行

### 5.4 数据管理卡

目标：让家长掌握本地数据，不被锁死。

MVP 内容：

- 导出本地学习数据
- 导入本地学习数据
- 重置全部学习记录
- 重置仅当日任务

风险控制：

- 重置操作必须有二次确认
- 导入操作要先做格式校验

## 6. 页面状态

### 6.1 默认状态

- 读取 ParentSetting
- 没有记录时加载 defaultParentSetting

### 6.2 保存中状态

- 开关或步进器调整后立即保存
- 保存时不打断页面，只做轻提示

### 6.3 导入失败状态

- 提示格式不合法
- 不覆盖旧数据

### 6.4 重置确认状态

- 弹确认对话框
- 明确说明影响范围

## 7. 关键交互

### 7.1 修改每日新词数

- 保存后影响复习页首页建议和未来压力估算

### 7.2 修改每日复习上限

- 保存后影响统计页和选词页的压力标签

### 7.3 关闭发音

- 学习页隐藏发音按钮或禁用播放

### 7.4 导出数据

- 导出 ParentSetting、DailyTaskSummary、LearningRecord、WordSelectionState

### 7.5 重置学习记录

- 清空学习进度，不删除词库数据

## 8. 组件建议

- SettingsPage
- SettingsSectionCard
- SettingsNumberControl
- SettingsToggleRow
- PwaInstallHintCard
- DataManagementCard

## 9. 与其他页面联动

### 9.1 与复习页联动

- 学习量设置影响首页任务强度和建议文案

### 9.2 与学习页联动

- 发音、图片、例句、提示开关会改变学习页显示

### 9.3 与统计页联动

- dailyReviewLimit 影响未来压力判断阈值

## 10. 推荐实现顺序

1. 扩展 ParentSetting 模型
2. 完成学习量设置卡
3. 完成学习体验设置卡
4. 完成数据管理卡
5. 补 PWA 安装提示

## 11. 结论

设置页的目标不是提供很多配置，而是把真正影响学习效果的少数控制项做清楚、做安全。

它应该是家长放心修改参数的地方，而不是需要学习成本的后台。
