# VocaRabbit 选词页设计

日期：2026-05-08

## 1. 设计目标

选词页是家长配置学习范围的核心页面。

它不是单纯的词库浏览页，而是一个带决策能力的配置面板。家长需要在这页完成三件事：

1. 找到合适的词。
2. 决定哪些词现在启用，哪些词先暂停。
3. 立刻看到这个选择会不会让未来复习压力失控。

设计原则：

- iPad 横屏优先，支持同时看筛选、单词和已选结果。
- 批量操作优先于逐词点选。
- 所有筛选动作都应该实时反馈到右侧压力估算。
- 页面重点是“做决定”，不是“看很多信息”。

## 2. 页面定位

选词页属于四个主页面之一，对应底部导航中的“选词”。

它和其他页面的关系：

- 复习页回答今天学什么。
- 选词页决定允许学什么。
- 统计页解释这样选以后学得怎么样。
- 设置页调整每天学多少。

所以选词页在整个产品里承担的是“词库范围控制器”的职责。

## 3. MVP 能力边界

### 3.1 当前模型已经有的能力

根据当前 [vocab_rabbit/src/models/word.ts](vocab_rabbit/src/models/word.ts)、[vocab_rabbit/src/models/learning-record.ts](vocab_rabbit/src/models/learning-record.ts) 和 [vocab_rabbit/src/models/parent-setting.ts](vocab_rabbit/src/models/parent-setting.ts)，已经可以稳定使用的字段有：

- 单词英文、中文、分类、词性、难度
- 图片是否已经通过审核
- 牛津树定位
- 学习掌握等级
- 错误次数
- 下次复习时间
- 每日新词数和每日复习上限

### 3.2 当前模型还缺的能力

要把选词页做完整，当前还缺三类状态：

1. 启用 / 暂停状态
2. 自定义词单归属
3. 词库配置变更时间

所以这份设计会明确新增最小模型，而不是假装当前数据已经足够。

## 4. 推荐布局

推荐采用 iPad 横屏三栏式。

```text
┌────────────────────────────────────────────────────────────────────┐
│ 选词页标题  搜索框  启用词数  已掌握词数  未来3天复习压力         │
├───────────────┬────────────────────────────────┬───────────────────┤
│ 左侧筛选栏    │ 中间单词区                       │ 右侧已选词篮      │
│               │                                │                   │
│ 分类          │ 工具条：视图/排序/批量操作       │ 已启用词数         │
│ Level         │                                │ 已暂停词数         │
│ 难度          │ [卡片][卡片][卡片][卡片]        │ 分类占比           │
│ 词性          │ [卡片][卡片][卡片][卡片]        │ 未来3天压力         │
│ 状态          │ [卡片][卡片][卡片][卡片]        │ 建议动作           │
│ 图片/例句     │                                │ 保存方案 / 应用    │
└───────────────┴────────────────────────────────┴───────────────────┘
```

推荐理由：

- 左侧专门做筛选，不污染内容区。
- 中间专门做词本身的浏览和批量选择。
- 右侧实时显示选择结果和压力，不需要来回跳页面。

## 5. 页面模块

### 5.1 顶部总览条

目标：家长一进入页面就看到当前词库配置的总体状态。

MVP 放 5 个指标：

1. 当前启用词数
2. 当前暂停词数
3. 已掌握词数
4. 未来 3 天预计复习量
5. 当前筛选结果数量

交互：

- 点击启用词数，滚动到右侧词篮顶部。
- 点击未来 3 天预计复习量，高亮压力模块。

### 5.2 左侧筛选栏

目标：让家长快速缩小词库范围。

MVP 筛选项：

1. 分类
2. 牛津树首次出现 Level
3. 难度 1-5
4. 词性
5. 学习状态
6. 是否有已审核图片

学习状态建议先做 4 桶：

- 未学
- 学习中
- 已掌握
- 已暂停

注意：已暂停需要依赖新增的选词状态模型。

增强筛选：

- 是否有例句
- 是否有助记
- 错误次数高于某阈值
- 未来 3 天内将到期

### 5.3 搜索区

目标：支持家长按中文或英文快速定位单词。

MVP 规则：

- 同时支持英文前缀和中文包含搜索。
- 输入后立即过滤，不需要单独提交。
- 空搜索时恢复当前筛选结果。

增强规则：

- 支持多个关键词。
- 支持搜索分类名。

### 5.4 中间单词区

目标：展示可操作的词卡，而不是只显示一张长表。

MVP 提供两种视图：

1. 卡片视图，默认一行四卡
2. 列表视图，适合大批量操作

卡片必须展示：

- 英文
- 中文
- 分类
- 词性
- 难度
- 牛津树定位
- 当前状态标签
- 启用 / 暂停按钮
- 打开详情按钮

卡片交互：

- 单击卡片主体：打开单词详情抽屉
- 单击状态按钮：切换启用 / 暂停
- 长按或多选模式：加入批量操作集合

### 5.5 批量操作工具条

目标：避免家长逐词点选造成操作成本过高。

MVP 批量操作：

1. 启用当前筛选结果
2. 暂停当前筛选结果
3. 只保留当前筛选结果
4. 清空当前筛选

增强操作：

- 保存为自定义词单
- 从现有词单追加

### 5.6 右侧已选词篮

目标：把当前配置结果可视化，而不只是显示一个数字。

MVP 内容：

1. 已启用词数
2. 已暂停词数
3. 分类分布
4. 明天预计复习量
5. 未来 3 天预计复习量
6. 风险标签：正常 / 偏高 / 过高
7. 立即应用按钮

建议把词篮理解成“当前学习计划摘要”，而不是购物车。

### 5.7 压力预估模块

目标：选词页最关键的反馈机制。

这部分必须放在右侧词篮中实时更新。

MVP 计算：

- 预计启用词带来的明天到期量
- 未来 3 天到期量
- 是否超过每日复习上限

展示方式：

- 一个简化柱状图
- 一段风险文案
- 一条建议动作

建议动作优先级：

1. 如果压力正常：继续当前方案
2. 如果压力偏高：降低新词数
3. 如果压力过高：暂停部分主题或暂时只复习

## 6. 单词详情抽屉在选词页里的职责

选词页里的详情抽屉不只是信息展示，而是决策辅助面板。

MVP 内容：

- 英文
- 中文
- 词性
- 分类
- 发音
- 图片
- 牛津树定位
- 当前掌握等级
- wrongCount
- nextDueAt
- 启用 / 暂停开关

增强内容：

- 例句
- 助记
- 最近学习记录
- 过去是否被频繁答错

## 7. 数据模型建议

### 7.1 建议新增模型

当前最小需要新增：

```ts
interface WordSelectionState {
  wordId: string;
  isEnabled: boolean;
  isPaused: boolean;
  sourceListId?: string | null;
  updatedAt: string;
}
```

说明：

- isEnabled 用于决定该词是否进入学习计划。
- isPaused 用于短期停用而不丢失配置历史。
- sourceListId 先预留，为自定义词单做准备。

### 7.2 不建议一开始就加的模型

以下能力先不进入 MVP：

- 多个命名词单之间的复杂继承关系
- 词单共享
- 云端词单同步

## 8. 数据口径

### 8.1 当前启用词数

来源：WordSelectionState.isEnabled = true

### 8.2 当前暂停词数

来源：WordSelectionState.isPaused = true

### 8.3 已掌握词数

来源：LearningRecord

规则：masteryLevel >= 4

### 8.4 学习状态筛选

建议映射：

- 未学：没有 LearningRecord
- 学习中：LearningRecord 存在且 masteryLevel < 4
- 已掌握：masteryLevel >= 4
- 已暂停：WordSelectionState.isPaused = true

### 8.5 Level 筛选

来源：WordRecord.oxfordRefs 的第一条记录

规则：

- 没有 oxfordRefs 的词可以归入“未知 Level”桶

### 8.6 图片筛选

来源：WordRecord.imageApproved

规则：

- 已审核图片：imageApproved = true
- 无可靠图片：imageApproved = false

## 9. 页面状态

### 9.1 首次使用

如果还没有 WordSelectionState：

- 默认显示全部词可浏览
- 右侧显示“尚未配置词库”引导卡
- 提供快速预设按钮：
  - 全量 KET
  - 低难度优先
  - 只启用有图片词

### 9.2 当前筛选无结果

- 显示空状态，不显示空白网格
- 提供两个按钮：清空筛选、放宽条件

### 9.3 已选词过少

如果启用词数过低：

- 压力模块显示“学习量偏低，可能不足以形成稳定计划”

### 9.4 已选词过多

如果启用词数过高并造成未来压力过高：

- 显示红色风险标签
- 给出一键建议：暂停高难词、只保留低 Level 词、只保留有图词

## 10. 与其他页面的联动

### 10.1 与复习页联动

- 应用当前词库方案后，回到复习页刷新今日任务
- 复习页中的四词预览来源于当前启用词范围

### 10.2 与统计页联动

- 统计页点击高错误主题后，跳到选词页并带上分类筛选
- 统计页点击“收缩压力”后，跳到选词页并高亮压力模块

### 10.3 与设置页联动

- 每日新词数和每日复习上限会直接影响右侧压力估算

## 12. 推荐实现顺序

### Phase 1

- WordSelectionState 模型与存储
- 选词页页面框架
- 左侧筛选
- 中间词卡区
- 启用 / 暂停按钮
- 右侧词篮摘要

### Phase 2

- 搜索
- 批量操作
- 压力预估
- 和复习页的任务刷新联动

### Phase 3

- 自定义词单
- 高级筛选
- 统计页联动跳转

## 13. 结论

选词页的关键不是“浏览单词”，而是“控制学习范围并立即看到后果”。

只要围绕这个原则实现：

- 左边负责缩小范围
- 中间负责看词和操作
- 右边负责显示后果

它就会成为整个 VocaRabbit 家长配置体系的核心页面，而不是另一个堆满筛选器但实际很难做决策的设置页。
