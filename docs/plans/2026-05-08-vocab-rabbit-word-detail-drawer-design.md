# VocaRabbit 单词详情抽屉设计

日期：2026-05-08

## 1. 设计目标

单词详情抽屉是整个产品的横向通用层。

它的职责不是单纯放更多信息，而是在不离开当前页面的前提下，给出“理解这个词”和“对这个词采取操作”的能力。

它要支持三类场景：

1. 在复习页看预览词时，快速理解词内容。
2. 在选词页里，决定要不要启用、暂停或移出某个词。
3. 在统计页里，分析为什么某个词会成为薄弱词。

## 2. 页面定位

详情抽屉不是独立页面，而是全局覆盖层。

触发入口：

- 复习页的预览词卡
- 选词页的词卡或列表行
- 统计页的高频错误词列表

关闭方式：

- 点击关闭按钮
- 点击遮罩层
- 向右滑动关闭（iPad 可选增强）

## 3. 当前数据基线

当前 WordRecord 已支持：

- 英文
- 中文
- 词性
- 分类
- 难度
- 图片路径
- 图片审核状态
- 牛津树定位

当前 LearningRecord 已支持：

- masteryLevel
- reviewStage
- wrongCount
- lastStudiedAt
- nextDueAt

因此当前 MVP 可以稳定展示：

- 词条基础信息
- 学习状态
- 错误次数
- 下次复习时间

但当前还缺：

- 例句字段
- 音标字段
- 助记字段
- 逐次答题记录

这些内容可以作为增强项预留。

## 4. 抽屉结构

推荐采用右侧滑出抽屉，iPad 横屏宽度约占 32% 到 40%。

```text
┌──────────────────────────────┐
│ 顶部：英文 + 发音 + 关闭      │
├──────────────────────────────┤
│ 中文 / 词性 / 分类 / 难度     │
├──────────────────────────────┤
│ 图片区                        │
├──────────────────────────────┤
│ 牛津树定位                    │
├──────────────────────────────┤
│ 学习状态 / 错误次数 / 下次复习 │
├──────────────────────────────┤
│ 例句 / 助记（增强）           │
├──────────────────────────────┤
│ 操作区：启用 / 暂停 / 重置    │
└──────────────────────────────┘
```

## 5. 模块清单

### 5.1 顶部信息区

MVP 内容：

- 英文单词
- 发音按钮
- 关闭按钮

增强内容：

- 音标

### 5.2 基础信息区

MVP 内容：

- 中文释义
- 词性
- 分类
- 难度

### 5.3 图片区

MVP 内容：

- 主图
- 无图时显示占位状态

增强内容：

- 多张候选图切换
- 图片审核状态说明

### 5.4 牛津树定位区

MVP 内容：

- 第一处定位
- 第二处定位（如果有）

展示格式建议继续沿用当前风格：

- Level x,y,z

### 5.5 学习状态区

MVP 内容：

- masteryLevel
- reviewStage
- wrongCount
- lastStudiedAt
- nextDueAt

目标：让家长知道这个词当前难不难、稳不稳、何时再来。

### 5.6 操作区

MVP 动作：

- 启用该词
- 暂停该词
- 移出当前学习计划

增强动作：

- 重置该词学习记录
- 加入重点复习

动作区需要根据页面上下文微调：

- 从复习页打开时，以查看为主
- 从选词页打开时，以启用/暂停为主
- 从统计页打开时，以分析和修复为主

## 6. 上下文模式

建议详情抽屉支持 3 种上下文模式：

### 6.1 Review 模式

重点：快速理解词内容

默认显示：

- 英文
- 中文
- 图片
- 发音
- 牛津树定位

### 6.2 Selection 模式

重点：快速决定是否启用或暂停

默认显示：

- 基础信息
- 学习状态
- 启用/暂停操作

### 6.3 Statistics 模式

重点：理解这个词为什么是薄弱词

默认显示：

- 基础信息
- wrongCount
- masteryLevel
- nextDueAt
- 去复习 / 去选词页调整

## 7. 页面状态

### 7.1 无图片

- 显示占位图
- 标注“暂未接入图片”

### 7.2 无牛津树定位

- 显示“暂无牛津树定位”

### 7.3 无学习记录

- 显示“尚未开始学习”
- 隐藏错误次数和下次复习的具体时间

### 7.4 数据不完整

- 模块局部降级显示，不阻断整个抽屉

## 8. 交互原则

1. 默认打开速度要快，优先展示已有字段。
2. 抽屉中的操作完成后，要同步刷新触发页面。
3. 不让用户为了看一个词跳到新页面。
4. 右侧抽屉不应过宽，避免遮住主页面全部内容。

## 9. 组件建议

- WordDetailDrawer
- WordDetailHeader
- WordDetailMeta
- WordDetailImagePanel
- WordDetailOxfordRefs
- WordDetailLearningStatus
- WordDetailActions

## 10. 推荐实现顺序

1. 先支持复习页和选词页中的词卡打开抽屉
2. 接入基础信息、图片、牛津树定位、学习状态
3. 接入启用/暂停动作
4. 再接统计页中的高频错误词入口

## 11. 结论

单词详情抽屉不是锦上添花，而是 VocaRabbit 里承接“词内容”和“词操作”的关键通用层。

只要这个抽屉设计稳定，后面复习页、选词页、统计页的很多复杂跳转都可以被压缩成“留在当前页里看一个词”。
